name: 定期レポートはチャットで受け取る
description: HK の定期自動実行の要件。レポートは「続きの会話ができるセッション」に届ける。メール・ファイル出力は差し戻し済み
type: feedback
last_verified: 2026-09-10
---

HK が定期実行（毎朝の巡回など）に求めるのは「レポートが届くこと」ではなく「会話が始まっていること」。読んだ直後にその場で「MU をもっと調べて」と続けたい。

**Why**: メールとファイル出力は一方通行で読んで終わりになる。2026-09-09 に Gmail SMTP 配信で実装したところ差し戻された（「要件を取り違えていた」）。

**How to apply**:
- 定期実行の成果物は、スマホから開いて返信できるセッションに出す。HK のローカルセッションは `remoteControlAtStartup: true` で全部 Remote Control に載るので、Task Scheduler から対話 claude を固定セッション ID で `--resume` 起動すれば「同じスレッドに毎朝追記」になる（実例 invenstment の `scripts/run_patrol.cmd`）
- 「毎回新しいセッションが立つ」設計は迷惑と明言された。デスクトップアプリの scheduled task は毎回新規セッションなので不適
- 他プロジェクトで同じ要望が出たら invenstment の仕組みをそのまま写す。手本は `[[ローカル定期実行の落とし穴]]`
