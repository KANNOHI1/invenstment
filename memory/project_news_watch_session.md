ニュース監視は 2026-09-14 に菅野さんが役割を指定した第3セッション（`保有銘柄NEWS [f99e63]`、旧名 `invenstment-71`、Claude Code セッション `session_01WGJPVTS7JvPDRKFfWXwcge`）。**指示文の正は `watchlist/news_watch_prompt_v1.md`**（git 追跡。巡回の手順がこのファイルの存在を前提にする）。ここには指示文に書かない「なぜ」だけ置く。

**受け渡しは3経路で、ファイルが唯一の恒久経路。**
- 巡回（07:00）はバケツ4「保有銘柄の材料」を `claude_logs/news/YYYY-MM-DD.md` から読む。25分差で書きかけを読む事故を避けるため **tmp→rename**（同一ディレクトリ内 rename は原子的。完了行方式は書き忘れ1回で破れるので不採用）。
- 監督へは `SendMessage`。**セッションが改名・再起動すると pipe アドレスが失効する**（2026-09-16 朝に `invenstment-12` が `投資（監督）` へ改名し ENOINBOX）。失敗したら再送せず `ListAgents` で引き直し、ユーザー向け報告に「監督へ未達」と書く。ファイルは残るので情報は落ちない。
- ユーザーへはこのセッションで銘柄ごと1行。

**監督と合意した型（各1回の失敗から）**
- 「窓外だがリポジトリ未記録」の事実は 1行目の「要注意 N 件」に出す。「なし」に混ぜると監督が詳細を読まない日に落ちる（初回に MOD の RMT を「なし」に混ぜた）。
- |日次| > 8% の保有銘柄を「なし」で出さない。深掘りしても不明なら「銘柄固有の大幅変動・原因未確認」。理由を埋めない（POWL「Russell 2000 除外」誤報、SIMO 9/14 -16.8% を「なし」で出した取りこぼし）。
- 反証条件に掛かりそうな事実は条件名を添えるだけで判定しない。価格の条件は作らない（原因未確認の下げを条件化すると 9/12 に棄却した「乖離＝前兆」と同じ過ち）。
- 確認段階は 確認済／二次のみ／未確認 の3段階。アナリストのレポート本文は非公開なので格上げ・格下げは「二次のみ」が上限。

**構造的な事実**: SIMO は Nasdaq ADS のみで台湾非上場 → MOPS・月次営収は存在しない。SIMO の決算日程は約3週間前に 6-K で告知される（2025 Q3: 10/8 告知→10/30 結果）。

**cron は保険なし。** `51c9ea20`（06:35）と `907f218a`（22:05 MOD M0/M2）はこのセッションの窓が開いている間だけ動き、7日で失効する。巡回のような Task Scheduler の保険は付けていない。関連: [[巡回の固定セッションIDと3セッション体制]] [[ローカル定期実行の落とし穴]]
