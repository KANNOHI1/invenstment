# DELL 深掘りメモ - 2026-05-07

## 位置づけ

`DELL`は、メモリ / ストレージ山にも名前が出ているが、本質的には「AIサーバー / ストレージ / ネットワークを統合して納めるAIインフラ企業」。

`MU`や`SNDK`のようなメモリ価格・供給制約の直接レバレッジではなく、AIデータセンター構築の量を取り込む企業として見る。

中心問い:

> Dellは、AIサーバー受注残を利益に変えられるのか。それとも、売上は急増するがGPU/メモリなど部材コストが重く、薄利の通過売上で終わるのか。

## AIサーバーの事実

FY2026のAIサーバー関連:

- AI最適化サーバー受注: 640億ドル超。
- FY2026出荷: 250億ドル超。
- FY2027期首バックログ: 430億ドル。

- FY2027 AI最適化サーバー売上見通し: 約500億ドル。

これは非常に強い。

AIサーバー需要が本物であること、Dellが巨大受注を取れていることは疑いにくい。

## 何が良いのか

### 1. AIサーバー受注残が巨大

430億ドルのAIバックログは、FY2027売上の可視性をかなり上げる。

`SNDK`のRPO 416億ドルとは性格が違うが、AI需要が受注として見えている点では強い。

### 2. FY2027ガイド基準ではPERがそこまで高くない

現在株価238.80ドルに対して、FY2027 Non-GAAP EPSガイド12.90ドルなら、PERは約18.5倍。

表面PER31.9倍だけで見るよりは安く見える。

ただし、`MU`のQ3年率化PER約8.7倍、`SNDK`のQ4年率化PER約10.7〜11.8倍よりは高い。

### 3. キャッシュフローが強い

FY2026の営業キャッシュフローは111.85億ドル、フリーキャッシュフローは85.55億ドル。

薄利サーバー売上だけでなく、実際にキャッシュが出ている点は重要。

### 4. AIサーバーだけでなくDell AI Factoryの統合提案がある

Dellはサーバー、ストレージ、ネットワーク、NVIDIA連携、サービスまで含む統合提案を進めている。

単なる箱売りから、より高付加価値のAIインフラ統合へ寄せられるなら、マージン懸念を一部相殺できる。

## 懸念点

### 1. AIサーバーはマージンが薄い可能性

FY2026のNon-GAAP粗利率は20.4%。前年は22.8%。

Q4でもNon-GAAP粗利率は20.5%で、前年同期の24.3%から低下。

売上は急増しているが、AIサーバーミックスが粗利率を押し下げている可能性が高い。

これはDellの最大リスク。

### 2. メモリ/ストレージ山の直接レバレッジではない

DellはメモリやSSD価格の上昇を直接享受するというより、むしろ部材コスト上昇を受ける側。

`MU`や`SNDK`が高粗利で儲かる局面では、Dellは調達コストが上がりやすい。

したがって、メモリ山の購入候補としては一段落とす。

### 3. 3倍数学はやや重い

3倍時価総額は約4,747億ドル。

これを正当化するには、例えば次のような条件が必要。

- EPS 25ドル × PER 28倍。
- EPS 30ドル × PER 24倍。
- AIサーバー500億ドル売上が、薄利ではなく十分な営業利益を生む。

FY2027ガイドEPS12.90ドルから見ると、3倍にはまだ利益が足りない。

### 4. 顧客集中・Neocloud依存の可能性

AIサーバー需要は、ハイパースケーラー、Neocloud、xAI/CoreWeave型顧客に集中しやすい。

顧客の資金調達、GPU需給、AI投資サイクルが変わると、バックログの質が問われる。

## 爆益シナリオ

### シナリオA: FY2027ガイドどおり進む

FY2027 Non-GAAP EPS 12.90ドル、PER 20倍なら株価258ドル。

現在株価からは小幅上昇。

このシナリオは「良い会社だが爆益ではない」。

### シナリオB: AIサーバー売上500億ドルが高収益化する

AIサーバー売上が500億ドルに達し、サービス/ストレージ/ネットワーク込みでマージンが改善する場合。

EPS 18〜20ドル、PER 22〜25倍なら、株価は396〜500ドル。

現在株価から約1.7〜2.1倍。

### シナリオC: AI Factory型の統合インフラ企業として再評価

Dellが単なるサーバー組立ではなく、AIインフラ統合の標準企業として見られる場合。

EPS 25ドル、PER 25倍なら株価625ドル。

現在株価から約2.6倍。

3倍には近づくが、かなり強い実行が必要。

## 初期判定

`DELL`は良い会社だが、メモリ/ストレージ山の購入候補としては`MU`、`SNDK`、`SIMO`より優先度を下げる。

理由:

- メモリ価格上昇の直接受益ではない。
- AIサーバー売上は大きいが、マージンが薄い。
- FY2027ガイドPERは安すぎるほどではない。
- 3倍以上を狙うには、AIサーバー高収益化が必要。

一方で、AIインフラ統合山では重要候補として残す。

暫定順位:

1. メモリ山の主候補: `MU`
2. メモリ山の攻撃候補: `SNDK`
3. 小型寄り準主役候補: `SIMO`
4. AIインフラ統合候補: `DELL`
5. HDDテーマ確認: `WDC` / `STX`

## 次に見るべきこと

1. Q1 FY2027決算で、AIサーバー売上500億ドルガイドへの進捗。
2. AIサーバー粗利率 / ISG営業利益率が改善するか。
3. バックログ430億ドルの顧客構成とキャンセルリスク。
4. Storage売上がAI Factoryと連動して伸びるか。
5. `SMCI`、`HPE`、`VRT`、`NVDA`との利益配分比較。

## 暫定スタンス

`DELL`は、最終候補から完全除外ではない。

ただし、メモリ株として買う銘柄ではない。

現在は、

- メモリ/ストレージ購入候補: `MU`、`SNDK`、`SIMO`
- AIサーバー/統合インフラ候補: `DELL`

として分けるのが正しい。
