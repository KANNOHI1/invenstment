# research フォルダ運用

このフォルダは、投資テーマごとの一次情報・調査ノート・深掘りメモを置く場所。

## フォルダ構成

| フォルダ | 用途 |
| --- | --- |
| `00_inbox_x_posts` | X投稿の取り込み、画像、初期ダイジェスト |
| `00_framework` | 床マップ、マルチバガー評価フレームなど横断メモ |
| `00_earnings_monitor` | 決算予定銘柄の公式IR巡回結果、自動監視ステータス、HTMLスナップショット |
| `memory_storage` | メモリ、ストレージ、HDD/SSD、NAND/DRAM関連 |
| `optical_photonics` | 光通信、フォトニクス、CPO、SiPh、検査 |
| `ai_chips_accelerators` | AIチップ、GPU/アクセラレータ、カスタムASIC、AIサーバー、エッジAI SoC |
| `ai_server_infrastructure` | AIサーバー、統合インフラ、サーバーベンダー |
| `ai_physical_infrastructure` | 配電、電力制御、冷却、施工、AIデータセンター物理ボトルネック |
| `water_cooling_infrastructure` | 水処理、水計測、液冷、水インフラ、データセンター冷却周辺 |
| `nuclear_power_infrastructure` | 原子力、SMR、先進炉、燃料、既存発電、データセンター電力 |
| `neocloud_ai_datacenter` | Neocloud、AIクラウド、HPCコロケーション、AIデータセンター運営 |
| `rare_earth_magnets` | 希土類、永久磁石、重希土類、ロボット/防衛/EV/産業モーター供給網 |
| `defense_edge_ai_drones` | 防衛AI、エッジAI、ドローン、カウンターUAS、自律システム、rugged compute |
| `healthcare_ai` | 医療AI、精密医療データ、診断、製薬向けデータ/モデル、黒字化前の爆発力枠 |

## 運用ルール

- 新しい山を始めたら、まずこの直下にテーマ別フォルダを作る。
- 個別銘柄の深掘りは、該当テーマフォルダに置く。
- X投稿や画像は、最初は`00_inbox_x_posts`に置き、必要なら後でテーマ別フォルダから参照する。
- 比較表や購入候補リストは`watchlist`に置く。
