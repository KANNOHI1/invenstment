# 投資アイデア床マップ - 2026-05-07

## 目的

これは「部屋の床に全部広げる」ための地図。ランキングでも買いリストでもない。

目的は、見つけたアイデアを漏らさず見える化し、似たものを同じ山にまとめ、真剣な配分議論の前に何を検証すべきか決めること。

## 中心問い

現在の作業仮説:

> AIインフラ投資は、次々に物理的ボトルネックを生む。最大のリターンは、まだ機関投資家が完全に織り込んでいない「次の詰まり」から出る可能性がある。

これはGEV/MUの教訓を拡張したもの。

- マルチバガーになるために、企業が極小である必要はない。
- 重要なのは、古い評価軸と新しい利益・供給制約の現実がズレていること。
- Pattern Bの既存事業再評価は、純粋な小型バイナリーより期待値が高い場合がある。

## 床に広げた山

### 1. メモリ / ストレージ再評価

床にあるもの:

- MU
- SNDK
- WDC
- キオクシア
- SK Hynix
- Samsung Electronics
- STX
- Silicon Motion
- P（旧Pure Storage / 旧PSTG）
- PSTG（旧ティッカー、参照用）
- NTAP
- DELL

なぜ重要か:

- AIの学習・推論には、HBM、DRAM、NAND、SSD、ストレージシステムが必要。
- ここでの核心は単なる売上成長ではなく、「利益水準のリセット + 評価軸のリセット」。
- SNDK/MUは、すでに大きい企業でも予想EPSの変化が市場認識より速いと大きく再評価される例。

確認すべきこと:

- メモリ価格・NAND価格はまだ上昇しているか。
- 粗利率改善は循環的か、構造的か。
- ハイパースケーラーとの供給契約は複数年・供給制約付きか。
- 市場は現在どのEPS水準を織り込んでいるか。
- 3倍/5倍/10倍時の時価総額は現実的か。

主なリスク:

- サイクル反転
- 設備投資による供給過剰
- 顧客集中
- コモディティ価格崩壊
- 急騰後の織り込み済みリスク

### 2. AIチップ / アクセラレータ / サーバー周辺

床にあるもの:

- NVDA
- AMD
- AVGO
- MRVL
- TSM
- INTC

なぜ重要か:

- AIインフラの中心はGPU/アクセラレータ、ASIC、ネットワーク半導体、サーバー統合、ファウンドリ能力。
- ただし、この山はすでに市場の主戦場になっており、銘柄によっては「次のボトルネック」ではなく「すでに織り込まれた勝者」になっている。
- `AMD`はメモリ/ストレージではなく、主にAIアクセラレータ/CPU/GPU側の候補として扱うのが自然。

確認すべきこと:

- AI向け売上比率と成長率。
- GPU/ASIC/サーバー供給制約がまだ続いているか。

- 10倍ではなく、3倍/5倍の数学で見た方がよい大型銘柄か。
- `AMD`については、NVDA追随ではなく、MIシリーズ/カスタムAIチップ/サーバーCPUの再評価余地を見る。

主なリスク:

- すでに高評価
- 競争激化
- 粗利率低下
- 顧客内製化
- 10倍時価総額が非現実的になりやすい

### 4. データセンター物理ボトルネック連鎖

床にあるもの:

- 作る: TSEM, FN, CLS

- 冷やす: VRT, MOD

なぜ重要か:

- AIデータセンターはチップだけでは完成しない。製造、検査、接続、配電、冷却、施工がすべて必要。
- 最も良いPattern B候補は、AI露出がまだ見出しで十分に認識されていない古い産業企業かもしれない。
- 市場がまだ古い産業株倍率で見ているなら、GEV型に近い。

確認すべきこと:

- 2026〜2027年に本当に詰まる工程はどこか。
- 受注残は売上より速く伸びているか。
- リードタイムは伸びているか。
- ハイパースケーラーやEPCとの長期供給契約はあるか。
- 単なる低マージン通過売上ではなく、営業レバレッジがあるか。

主なリスク:

- 旧来型景気循環
- 建設タイミング遅延
- 大型案件によるマージン希薄化
- 投資サイクル後の過剰能力
- すでに簡単な再評価が終わっているリスク

主なリスク:

- 収益化まで遠い
- 許認可・建設遅延

- IPO直後の過熱

### 6. 水 / 冷却インフラ

床にあるもの:

- XYL
- VLTO
- PNR
- ECL
- WTS
- AOS
- BMI
- DCI
- MWA
- TTEK
- WMS

なぜ重要か:

- 高密度AIデータセンターは、電力だけでなく熱管理にも負荷をかける。
- 液冷と水処理は、電力に続く二次的なボトルネックになる可能性がある。
- 投資対象の連鎖は水道株だけではない。ポンプ、ろ過、産業用水処理、計測、水質管理、熱交換、薬剤、水利用効率が含まれる。

VRT/MODとの違い:

- VRT/MODは電源・冷却装置・熱管理システム寄り。
- XYL/ECL/VLTO/PNR/WTS/BMIは水の移動、処理、品質、計測、制御寄り。
- 大型分散企業は10倍候補になりにくいが、水制約が許認可や運用上のボトルネックになるなら、より長いテーマになる可能性がある。

確認すべきこと:

- どの企業がデータセンター向け水・冷却エクスポージャーを明示しているか。
- AIデータセンターの液冷化で、特殊な水処理需要が増えるか。
- 原水使用量の増加ではなく、閉ループ・再利用・水効率化で恩恵を受ける企業はどこか。
- 大企業の中で埋もれず、株価に影響するほどの売上比率があるか。
- より直接的な冷却水レバレッジを持つ小型サプライヤーはあるか。

主なリスク:

- 大型ディフェンシブ企業では10倍余地が限定される
- データセンター露出が小さすぎる
- 地方自治体・公益向け売上がAIテーマを薄める
- サステナビリティ物語が実売上に先行する

### 10. 医療AI / 精密医療データ

なぜ重要か:

- `TEM`は今はGAAP赤字だが、2026年通期Adjusted EBITDA黒字化を会社がガイドしている。
- 黒字化を確認してからでは再評価が進んでいる可能性があるため、「赤字から黒字化が見える局面」の爆発力型として扱う。

- Adjusted EBITDA黒字化の確度。
- Data and Applications / Insightsの成長率。
- Diagnosticsの粗利率と検査volume growth。
- Operating cash flow / free cash flow改善の時期。
- SBC、希薄化、買収統合費用。
- 製薬契約、TCV、net revenue retention。

主なリスク:

- GAAP赤字継続
- 医療規制・保険償還
- 買収統合失敗
- SBC/希薄化
- データAIストーリーの過大評価
