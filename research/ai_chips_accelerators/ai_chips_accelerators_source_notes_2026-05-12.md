## 銘柄別メモ

### AMD

Q1 2026発表日: 2026-05-05

- Revenue: 102.53億ドル、前年比+38%
- Data center、EPYC server CPU、Instinct acceleratorsが主な論点
- MetaとAMDは最大6GWのAMD Instinct GPU導入計画を発表。最初の1GWはcustom AMD Instinct MI450-based GPU
- サーバーCPUはQ2に前年比+70%超成長見通しとの会社発言が報道されている

見方:

- すでに時価総額約7,500億ドルで巨大だが、NVDAの時価総額を考えると「大型でも数倍」視点で無視しない。
- 3倍には約2.26兆ドルが必要。爆益数学は重いが、AI accelerator + server CPU両方の再評価なら大型再評価枠。

### MRVL

Q4/FY2026発表日: 2026-03-05

- FY2026 revenue: 81.95億ドル、前年比+42%
- Robust AI demandが成長ドライバー
- Celestial AIとXConn Technologies買収はFY2027 Q1見通しに含まれる
- 次回Q1 FY2027は2026-05-27

見方:

- custom AI silicon、optical interconnect、data infrastructureの本命候補。
- 時価総額約1,469億ドルで大きいが、AVGOよりは軽い。
- 光通信/フォトニクス山とも重なるため、TSEM/CRDO/AAOIとの接続も見る。

### SMCI

Q3 FY2026発表日: 2026-05-05

- Net sales: 102億ドル、Q2 FY2026の127億ドルから減少、前年同期46億ドルから大幅増
- Q3 non-GAAP gross marginは10.1%、Q2の6.4%から改善
- AI server / liquid cooling integrationの実体は強いが、粗利率と顧客/出荷タイミングが弱点

見方:

- 時価総額約206億ドルで、この山の中では比較的軽い。
- 売上規模に対して時価総額は軽く見えるが、品質/ガバナンス/粗利率の警戒が必要。

### DELL

FY2026 Q4/FY2026通期発表日: 2026-02-26

- FY2026 revenue: 1,135億ドル、前年比+19%
- FY2026 AI-optimized server orders: 640億ドル超
- FY2027期首AI backlog: 430億ドル
- FY2027 AI-optimized servers revenue guide: 約500億ドル、前年比+103%
- Q1 FY2027は2026-05-28予定

見方:

- AI serverの巨大受注は本物。
- ただし統合サーバー企業であり、利益率が薄いと株価の上限が出やすい。
- Q1 FY2027でAI server revenueとISG marginを確認する。

### ARM

Q4/FY2026発表日: 2026-05-06

- Q4 FY2026 revenue: 14.9億ドル
- FY2026 revenue: 49.2億ドル
- FYE26は上場後3年連続で20%超 revenue growth
- FY2026 royalty revenue: 26.1億ドル
- data center royalties more than doubled year-over-year

見方:

- cloud AI、edge AI、physical AIのロイヤリティ本命。
- 時価総額約2,200億ドルで巨大。購入候補というより大型テーマ確認。

### AVGO

Q1 FY2026発表日: 2026-03-04

- Q1 revenue: 193.11億ドル、前年比+29%
- Q1 AI revenue: 84億ドル、前年比+106%
- Q2 FY2026 revenue guide: 約220億ドル
- Q2 AI semiconductor revenue見通し: 約107億ドル
- Q2 FY2026は2026-06-03予定

見方:

- custom AI accelerator + AI networkingでは本丸級。
- ただし時価総額約2兆ドル。爆益数学では重すぎるため、購入候補本線ではなく大型本命確認。

### AMBA

Q4/FY2026発表日: 2026-02-26

- Edge AI semiconductor company
- FY2026は新しいrevenue record
- FY2026 revenueの約80%がedge AI
- Cash + marketable securitiesは3億ドル超
- Q1 FY2027は2026-05-28予定

見方:

- この山で最も時価総額が軽い。
- 防衛/エッジAI/ドローン山とも接続する。
- ただし最新Q1 FY2027が近いので、購入候補化は決算後に判断する。

## 暫定見方

| 銘柄 | 型 | 現時点の役割 |
| --- | --- | --- |
| AMBA | Pattern A/B | 最軽量のedge AI SoC候補。Q1 FY2027待ち |
| SMCI | Pattern B | AI serverの売上規模に対して時価総額は軽いが、粗利率/品質リスク大 |
| MRVL | Pattern B/C | custom AI silicon / optical interconnectの本命候補。次回決算待ち |
| AMD | Pattern C | 大型再評価候補。MI/EPYC/Meta 6GWで無視しない |
| DELL | Pattern B/C | AI server巨大受注。Q1 FY2027で利益率確認 |
| ARM | Pattern C | AI/edge/cloud royalty本命。巨大で本線外寄り |
| AVGO | Pattern C | custom AI/AI networking本丸。巨大で本線外寄り |

現時点の深掘り優先は`SMCI`、`AMBA`、`MRVL`、`AMD`。ただし`AMBA`と`MRVL`は今月中に決算があるため、決算後に最終判断する。

`SMCI`は2026-05-12に深掘り済み。売上規模に対して時価総額は軽いが、粗利率、運転資金、輸出管理・ガバナンスの質が重いため、主軸ではなく条件付き候補として扱う。

`AMD`は2026-05-12に深掘り済み。Meta/OpenAI 6GW、Data Center +57%、FCF、粗利率は強いが、現在価格は期待先行。3倍狙いの大型再評価枠として残す。
