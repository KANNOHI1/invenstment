# NBIS Q1 2026決算アップデート - 2026-05-13

## 結論

`NBIS`は決算通過で「大型本命監視」から「大型でも候補化を検討する銘柄」へ格上げする。

ただし、既存のNeocloud購入候補である`IREN`/`CORZ`/`APLD`/`CIFR`を全部押しのけるというより、別枠で見る。

理由:

- Q1 2026売上は3.99億ドル、前年比+684%。
- adjusted EBITDAは1.295億ドルで黒字化。
- 2026-05-13の株価は204.00ドル、前日比+13.90%、52週高値205.02ドル近辺。
- 2026-05-13時点の株価204.00ドルとQ1末発行済み株式253,898,194株で見ると、時価総額は約518億ドル。
- 現金及び現金同等物は92.982億ドル。
- 一方で、non-current debtは84.32億ドル、Q1のPPE/無形資産購入は24.729億ドル。成長は本物だが、資本集約度も非常に高い。

## 良い点

### 1. 需要は本物

売上+684%は、Neocloud山の中でもかなり強い。Q1時点で売上3.99億ドルまで来たため、もはや単なるストーリー株ではない。

### 2. adjusted EBITDA黒字化

Q4時点でも黒字化が見えていたが、Q1でも1.295億ドルのadjusted EBITDAを出した。AIクラウドの売上が立つと、営業レバレッジはかなり強い。

### 3. 前受け/契約構造が強い

deferred revenueがcurrent/non-currentともに大きく増加。これは、将来売上の可視性が上がっているサイン。

### 4. 資金余力

現金92.982億ドルは強い。CapExを進めるための燃料はある。

## 悪い点

### 1. CapExが非常に重い

Q1だけでPPE/無形資産購入が24.729億ドル。これは売上3.99億ドルに対してかなり重い。

### 2. debtも増えている

non-current debtは84.32億ドル。今のAI需要が続く前提なら問題になりにくいが、GPUクラウド単価や稼働率が崩れると重い。

### 3. GAAP純利益は一過性要素が大きい

純利益6.212億ドルは見栄えが良いが、投資有価証券再評価益7.806億ドルの影響が大きい。本業営業利益はまだ赤字。

### 4. 株価は高値圏

決算後に株価は52週高値近辺。ここからの初回エントリーは、決算前よりかなり難しくなった。

## Neocloud山での扱い

従来:

- `NBIS`: 大型本命監視。Q1後に再採点。

更新後:

- `NBIS`: 大型でも候補化を検討。ただし初回から大きく買うより、押し目/追加開示待ち。

理由:

`NBIS`は、`CRWV`のような大型Neocloud本命側に近い。小型爆発力では`IREN`/`CORZ`/`APLD`/`CIFR`のほうが数学は軽いが、事業の質と成長速度は`NBIS`が上。

したがって、ロマン枠内では以下のように分ける。

| 役割 | 銘柄 |
| --- | --- |
| 事業品質・大型本命 | NBIS |
| 数学が軽い高リスク候補 | IREN / CORZ / APLD / CIFR |
| 既に巨大な比較対象 | CRWV |

## 配分への影響

既存のNeocloud配分:

| 銘柄 | 配分 |
| --- | ---: |
| IREN | 40% |
| CORZ | 25% |
| APLD | 20% |
| CIFR | 15% |

NBISを入れる場合の案:

| 銘柄 | 配分案 |
| --- | ---: |
| IREN | 35% |
| NBIS | 25% |
| CORZ | 20% |
| APLD | 12% |
| CIFR | 8% |

攻めるロマン枠としては、`NBIS`を入れるなら`CIFR`を削るのが自然。`CIFR`は数学は軽いが、現PLと契約詳細の弱さがあるため。

ただし、2026-05-13時点では`NBIS`が決算後急騰しているため、すぐ飛びつくより、押し目または次の契約/容量開示後にサイズを決める。

## 判断

`NBIS`決算はかなり良い。

「Q1後に監視から候補化するか」という問いには、候補化でよい。ただし、今日の急騰後に一気に買うより、Neocloud山の大型品質枠として、最初は小さく、押し目か次の容量/契約アップデートで追加する。
