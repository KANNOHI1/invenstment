# SIMO 深掘りメモ - 2026-05-07

## 位置づけ

`SIMO`は、メモリ / ストレージ山の中では、`MU`や`SNDK`とは違うタイプの候補。

MicronやSandiskのようにメモリ/NANDそのものを作る会社ではなく、SSD、eMMC、UFSなどのストレージ機器に使われるコントローラを設計する。

中心問い:

> AIデータセンター向けSSD需要が伸びる中で、Silicon Motionは「小さめのピックアンドショベル」として、MU/SNDKより軽い時価総額から非対称リターンを狙えるのか。

## 時価総額についての注意

`SIMO`はADS銘柄。

一部のマーケットデータでは、ADS価格に普通株数を掛けたような形で、時価総額が約330億ドルと表示される可能性がある。

ただし、公式決算リリース上のQ1希薄化ADS数は約3,391.6万ADS。現在株価244.95ドルを掛けると、推定時価総額は約83.1億ドル。

この差は投資判断に大きい。

- 時価総額330億ドルなら、10倍は3,300億ドルで重い。
- 時価総額83億ドルなら、10倍は831億ドルで、かなり難しいが完全に論外ではない。

以後、このメモでは推定時価総額83.1億ドルを基準にする。

## 何が良いのか

### 1. MU/SNDKより時価総額が軽い

推定時価総額83億ドルなら、MU/SNDK/WDC/STXとはまったく違うゲームになる。

3倍で約249億ドル、5倍で約415億ドル、10倍で約831億ドル。

AIストレージコントローラの勝者になれるなら、数学としてはまだ議論できる。

### 2. 売上成長が強い

Q1売上は前年同期比+105%。

Q2ガイドも前年同期比+98〜107%。

これは単なる「良い会社」ではなく、少なくとも今は急成長フェーズに入っている。

### 3. MonTitanがAI/クラウド向けの鍵

会社は、enterprise SSD controller `MonTitan`について、次のように説明している。

- Q1に量産開始。
- 2026年後半に5つのtier-one CSPへramp予定。
- AI cloud infrastructure、GPU infrastructure、edge AI、cloud AI devices向け需要を見込む。
- 2026年売上の5〜10%をenterprise SSD controllerが占める見込み。

ここが本物なら、SIMOは「スマホ/PC向けコントローラ会社」から「AIデータセンターSSDコントローラ会社」へ評価軸が変わる。

### 4. NANDメーカーではないので、CapEx地獄がない

MU/SNDKは供給を取るために大きな設備投資やJV負担が必要。

SIMOはファブレス寄りの設計会社なので、NAND価格上昇そのものには直接乗りにくいが、設備投資負担は比較的軽い。

ロマン枠としては、ここが魅力。

### 5. 粗利率・営業利益率が安定している

Non-GAAP粗利率は47%台、営業利益率は20%台。

爆発的な粗利率ではないが、設計会社として一定の収益性がある。

## 懸念点

### 1. Q1営業キャッシュフローがマイナス

Q1の営業キャッシュフローは-2,230万ドル。

理由は主に売掛金と在庫の増加。

急成長局面では自然な面もあるが、ロマン枠では「売上は伸びているがキャッシュがついてこない」リスクに注意する。

### 2. 在庫が増えている

Q1末の在庫は4.821億ドル。

2025年末の3.378億ドルから大きく増えている。

需要を見込んだ先行在庫なら良いが、顧客需要が鈍ると在庫評価損や粗利率低下につながる。

### 3. MonTitanはまだ売上の小さい部分

会社は2026年売上の5〜10%がenterprise SSD controllerになると見ている。

これは魅力的だが、現時点ではまだ会社全体を変えるほどの比率ではない。

本格的に評価軸が変わるには、MonTitanが2027年以降に20%超の売上構成へ上がる必要がある。

### 4. Q2ガイドでも高すぎるわけではないが、安くもない

Q2ガイド中央値で売上約4.02億ドル、Non-GAAP営業利益率約21.6%とすると、営業利益は約8,700万ドル。

税後・ADS数から概算すると、Q2 EPSは2.1〜2.3ドル程度のレンジが見える。

これを年率化するとEPSは8.4〜9.2ドル。

現在株価244.95ドルなら、年率化PERは約26〜29倍。

MUのQ3年率化PER約8.7倍と比べると、SIMOは明らかに高い。

### 5. コントローラは競争が激しい

SSDコントローラは重要部品だが、NANDメーカーや大手ASIC/半導体企業との競争もある。

MonTitanがtier-one CSPで本当に採用・量産され続けるかが重要。

## 爆益シナリオ

### シナリオA: MonTitanが2027年に本格化

Enterprise SSD controllerが2026年の売上5〜10%から、2027年に15〜25%へ上がる。

この場合、AIデータセンター向け企業として評価され、売上成長率とPERの両方が維持される可能性がある。

年EPS 12ドル、PER 35倍なら株価420ドル。

現在株価から約1.7倍。

### シナリオB: SSDコントローラの供給制約が顕在化

AIサーバー向けSSDの需要が急増し、コントローラがボトルネック化する。

SIMOが5社のtier-one CSPで設計勝ちし、MonTitanが複数世代に広がる。

年EPS 15ドル、PER 40倍なら株価600ドル。

現在株価から約2.4倍。

### シナリオC: 10倍には別格の変化が必要

10倍時価総額は約831億ドル。

これを正当化するには、例えば次のような状態が必要。

- 年EPS 25ドル超。
- PER 35倍以上。
- MonTitanがデータセンターSSDコントローラの事実上の標準になる。
- 売上が現在の年率16億ドル程度から50億ドル級へ伸びる。

これは現時点では相当強い仮説。

ただし、時価総額83億ドルスタートなら、MU/SNDKよりは10倍数学が軽い。

## 初期判定

`SIMO`は、購入候補から外すべきではない。

むしろ、時価総額を正しくADSベースで見るなら、メモリ/ストレージ山の中で「軽さ」は一番魅力的。

ただし、現時点では`MU`や`SNDK`より確度は低い。

理由:

- MonTitanはまだ全社売上の小さい部分。
- Q1営業CFがマイナス。
- 在庫増が大きい。
- Q2年率化PERは26〜29倍で、安値放置ではない。

暫定順位:

1. `MU`: 主候補。大型だが利益持続なら2〜3倍。
2. `SNDK`: 攻撃候補。RPOとSSD需要は強烈だが、ASPピークリスク。
3. `SIMO`: 小型寄り準主候補。MonTitan次第で3〜5倍余地。
4. `WDC` / `STX`: HDDテーマ確認用。現値からの非対称性は弱め。

## 次に見るべきこと

1. MonTitanの顧客名、設計勝ち、量産規模。
2. Enterprise SSD controllerの2026年5〜10%売上見通しが、2027年に何%へ伸びるか。
3. Q2決算で営業CFと在庫が改善するか。
4. 競合コントローラ企業と、NANDメーカー内製のリスク。
5. ADS/普通株比率と時価総額の扱いを継続確認する。

## 暫定スタンス

`SIMO`は、`MU/SNDK`の次に残す。

現在の候補整理:

- 本命: `MU`
- 攻撃: `SNDK`
- 小型寄りオプション: `SIMO`

SIMOの勝負は、MonTitanが単なる新製品ではなく、AIデータセンターSSDの構造的な標準部品になるかどうか。

現時点では、即主役ではなく、`Q2決算確認待ちの準主役候補`。
