# STX 深掘りメモ - 2026-05-07

## 位置づけ

`STX`は、WDCと並ぶHDD供給制約テーマの確認対象。

WDCが「Cloud売上89%」「上位顧客PO/LTA」でAI保存容量需要を示したのに対して、STXは「HAMR / Mozaicによる高容量化」と「データセンター向けmass-capacity storage」の供給制約を確認する銘柄。

中心問い:

> Seagateは、AI時代のデータ保存需要によって、成熟HDD企業から構造成長企業へ再評価されるのか。それとも、HDD供給不足のピーク利益を市場がすでに織り込んでいるのか。

## 何が強いのか

### 1. HDD需要はWDCだけの話ではない

STXも、AIアプリケーションがデータ生成を増幅し、持続的なストレージ需要を支えていると説明している。

WDCだけでなくSTXも同じ方向の数字を出しているため、HDD供給制約は単一企業の一時要因ではなく、セクター全体のテーマとして見る価値がある。

### 2. 数量も伸びている

Q3の出荷容量は199 exabytesで、前年同期比 +39%。

これはWDCのCloud exabytes +36%と整合する。

SNDK/MUのように「価格だけで跳ねている」わけではなく、HDD側は保存容量そのものが増えている。

### 3. 粗利率が記録的に改善

Non-GAAP粗利率47.0%、Non-GAAP営業利益率37.5%。

HDD企業としてはかなり高い。

会社側は、データセンター需要、製品ミックス、長期価格戦略が寄与していると説明している。

### 4. 契約の見通しが伸びている

Q3決算コールでは、主要顧客とのbuild-to-order契約をFiscal 2027末まで最終化しており、そこにはspecific configuration and pricingが定義されると説明している。

さらに、Calendar 2028以降に及ぶ戦略的計画の協議も進んでいる。

これはWDCの2027/2028年LTAと整合する。

ただし、SNDKのRPO416億ドルのように、会計上の巨大受注残としては見えない。

### 5. HAMR / Mozaicが技術差別化になる可能性

STXはMozaic 4+を例に、最大44TBのドライブを同じディスク/ヘッド数で実現できると説明している。

Mozaic 4は2026年3月末に売上出荷を開始し、2026年末にはHAMR exabyte出荷の過半を占める見込み。

Mozaic 5は50TBを目指し、2027年末にqualification shipmentを予定。

このロードマップが実行されるなら、単なるHDD価格上昇ではなく、高容量化による構造的なTCO改善がテーマになる。

## 爆益シナリオ

### シナリオA: Q4ガイド水準が続く

Q4ガイドのNon-GAAP EPSは5.00ドル。

単純年率化するとEPSは20ドル。

現在株価786.42ドルに対して、年率化PERは約39倍。

この見方では、STXはかなり高い。

### シナリオB: EPSが40ドル級へ上がる

HAMR/Mozaicの高容量化、価格条件付き契約、exabyte需要増が続き、EPSが40ドル級へ上がる場合。

PER 25倍なら株価1,000ドル。

現在株価からは約1.3倍。

これでも爆益とは言いにくい。

### シナリオC: 3倍にはEPSとPERの両方が必要

3倍株価は約2,360ドル。時価総額は約5,400億ドル。

これを正当化するには、例えば次のような条件が必要。

- EPS 80ドル × PER 30倍。
- EPS 100ドル × PER 24倍。

現在のQ4ガイド年率EPS20ドルから見ると、かなり遠い。

## 弱気シナリオ

### 1. すでに織り込みが重い

Q4ガイド年率化PERは約39倍。

これは成熟HDD企業としてはかなり高い。市場はすでにAIデータ保存テーマをかなり織り込んでいる。

### 2. 技術ロードマップ実行リスク

Mozaic 4/5、HAMR、顧客認定、量産歩留まりに遅れが出ると、高容量化によるTCO改善ストーリーが崩れる。

### 3. 顧客投資サイクル

クラウド/AI顧客がデータ保存インフラ投資を前倒ししている場合、発注が一巡すると成長が鈍る。

### 4. 価格がピークだった

長期契約・build-to-orderである程度守られるとしても、HDD供給が増え、需給が緩めば価格は下がる。

### 5. 株主還元株としての顔

配当と自社株買いは魅力だが、ロマン枠で狙う非対称リターンとは少し性格が違う。

## 初期判定

STXは、HDD供給制約テーマを確認するうえで重要。

ただし、現在株価からのロマン枠主役としては重い。

WDCより技術ストーリーは濃いが、バリュエーションも重く、3倍以上を狙うにはEPSの大幅拡大が必要。

暫定評価:

- テーマ確認銘柄としては重要。
- WDCとセットでHDD需要の実在性を見る。
- 現在価格からの主役候補としてはやや弱い。
- 大きな押し目があれば再評価。

## SNDK / WDC / MU / STXの暫定順位

爆益ロマン枠としての現在の見方:

1. `MU`: 巨大だが、Q3ガイド年率化PERが低く、2〜3倍シナリオが残る。
2. `SNDK`: 変化率は最大。ただし急騰後で、3倍以上には強い持続性が必要。
3. `WDC`: HDDテーマの基準銘柄。数量成長は良いが、爆発力は限定的。
4. `STX`: テーマ確認には重要だが、現在バリュエーションは重い。

この順位は「会社の良し悪し」ではなく、「今日の価格からロマン枠で狙う非対称性」の順位。
