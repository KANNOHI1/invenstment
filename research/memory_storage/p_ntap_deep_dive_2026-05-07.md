# P / NTAP 深掘りメモ - 2026-05-07

## 位置づけ

`P`（Everpure、旧Pure Storage / 旧PSTG）と`NTAP`（NetApp）は、メモリ / ストレージ山の中では「メモリ価格の直接レバレッジ」ではなく、データ基盤・ストレージ管理・エンタープライズストレージ側の候補。

中心問い:

> AI時代にデータ管理・ストレージ基盤の重要性が上がるとして、P/NTAPは爆益候補に残るのか。それとも、質は高いが成長率とバリュエーションのバランスからロマン枠主役には弱いのか。

## P / Everpure の事実

Pure Storageは2026年2月にEverpureへリブランドし、2026年4月17日からティッカーを`PSTG`から`P`へ変更。

FY2026の主な数字:

| 項目 | 数値 |
| --- | ---: |
| Q4売上 | 11億ドル、前年同期比 +20% |
| FY2026売上 | 37億ドル、前年比 +16% |
| Q4サブスクリプションARR | 19億ドル、前年比 +16% |
| RPO | 37億ドル、前年比 +40% |
| FY2026フリーキャッシュフロー | 6.16億ドル |
| Q4 Non-GAAP営業利益率 | 21.3% |

Pの良い点:

- RPO +40%で、将来売上の可視性がある。
- サブスクリプションARRが積み上がっている。
- FCFはしっかり出ている。
- AI時代のデータ管理というストーリーは分かりやすい。
- 時価総額は約236億ドルで、MU/SNDKより数学は軽い。

Pの弱い点:

- FY売上成長は+16%。ロマン枠としてはやや物足りない。
- FCF 6.16億ドルに対して時価総額約236億ドルなら、FCF利回りは約2.6%。
- 既に「質の高いデータ基盤株」としてある程度評価されている。
- AIという言葉は強いが、MonTitanのような明確な新製品レバレッジや、SNDKのRPO416億ドル級の爆発力はない。

初期判定:

`P`は悪くない。ただし、現時点では`MU`、`SNDK`、`SIMO`より優先度は下。

Pが再浮上する条件:

1. AIデータ管理/Portworx/サブスクリプションが20〜30%成長へ再加速する。
2. RPO成長が売上成長へ転換する。
3. FCF利回りが改善するか、株価が大きく押す。

## NTAP の事実

Q3 FY2026の主な数字:

| 項目 | 数値 |
| --- | ---: |
| 売上 | 17.13億ドル、前年同期比 +4% |
| Hybrid Cloud売上 | 15.39億ドル、前年同期比 +5% |
| Public Cloud売上 | 1.74億ドル、横ばい |
| All-flash array売上 | 10億ドル、前年同期比 +11% |
| Billings | 18.9億ドル、前年同期比 +10% |
| GAAP営業利益率 | 25.3% |
| Non-GAAP営業利益率 | 31.1% |
| GAAP EPS | 1.67ドル |
| Non-GAAP EPS | 2.12ドル |
| フリーキャッシュフロー | 2.71億ドル |
| Q4/FY2026決算予定 | 2026-05-28引け後 |

NTAPの良い点:

- Non-GAAP営業利益率31.1%で非常に高収益。
- All-flash arrayは+11%で、ストレージ内では強い。
- Billings +10%で、売上より少し先行指標は良い。
- 配当・自社株買いもあり、財務品質は高い。

NTAPの弱い点:

- 売上成長が+4%と低い。
- Public Cloud売上は横ばい。
- 10倍どころか3倍にも、成長再加速または大幅なPER再評価が必要。
- ロマン枠というより、質の高い成熟ストレージ株に見える。

初期判定:

`NTAP`は良い会社だが、爆益候補としては弱い。

現時点では、メモリ/ストレージ山の購入候補からは外してよい。

ただし、2026-05-28のQ4/FY2026決算で以下が出れば再評価する。

1. All-flash成長が20%台へ加速。
2. Public Cloudが再成長。
3. AI案件/受注残が数字で見える。
4. FY2027ガイドが市場想定を大きく上回る。

## 暫定スタンス

P/NTAPを確認した結果、メモリ/ストレージ山の購入候補はさらに絞れる。

- 本命: `MU`
- 攻撃候補: `SNDK`
- 小型寄り準主役: `SIMO`
- 監視: `P`
- 除外寄り: `NTAP`

P/NTAPは「良い会社」だが、ロマン枠の非対称性では`MU/SNDK/SIMO`に劣る。
