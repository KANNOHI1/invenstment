## この山の初期結論

- 最優先で見るべきは `SNDK`、`WDC`、`MU`。
- 次に、より小さいレバレッジとして `SIMO`。ADSベースの時価総額を使うと、数学は当初表示よりかなり軽い。
- `DELL`はストレージ山というよりAIサーバー/統合インフラ山にもまたがる。
- `P`と`NTAP`は質の高いデータ基盤株だが、爆益狙いでは「評価倍率がすでに高い/成長が穏やか」という問題を先に見る。
- `STX`は実需は強いが、現在倍率が高いので、良い会社と良い投資の距離を確認する。
- キオクシアは2026-05-15決算後に必ず再評価する。
