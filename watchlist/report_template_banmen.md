# 定型レポート「盤面」仕様 v0.2（ユーザーと作り込み中のドラフト）

2026-08-08改訂。ユーザー決定: ①毎朝の定期巡回は盤面の**差分版**に統一 ②手動で「盤面」と呼ばれたら**調査込みフル版**（3〜5分）を出す。

## 2つのモード

| モード | 起動 | 中身 |
|---|---|---|
| フル版 | ユーザーが「盤面」と発話 | 株価取り直し＋Web調査エージェント＋全5層 |
| 差分版 | 毎朝の定期巡回（自動） | 株価取り直し＋軽い材料確認。**冒頭に「前回から変わったこと」3行以内**、変化のない層は1行 |

## 生成手順（両モード共通）

1. `date -u +%Y-%m-%dT%H:%M:%SZ > watchlist/.price-refresh-trigger` → commit → push → `git pull` で `watchlist/latest_prices.json` を更新。**`quoteTime`を冒頭に明記。**
2. `watchlist/banmen_state.md`（前回の盤面要約）を読み、差分の基準にする。
3. `watchlist/thesis_register.md` の全反証条件を機械的にチェック。
4. フル版のみ: Web調査エージェントで市況の定性情報を取る。
5. レポート生成後、`banmen_state.md` を今回の要約で上書きし、コミットする。

## 5層構成（v0.2）

- **①マクロ**: 金利・雇用・インフレ・地政学・為替。盤面全体を動かしている一番大きい力。
- **②側とターン（心臓部）**: 今どの側にターンが来ているか——「計算力を貸す側」「装備を売る側」「AIの外側」等。**ターンの持ち主が変わったら「ターンチェンジ」として宣言する。** ローテーションの記述は根拠としてこの下に付く。
- **③テーマと仮説**: 冒頭に仮説登録簿チェック結果の固定枠（反証該当なしなら1行）。続けて保有に関わる山ごとの新材料。
- **④保有**: 縦型2行フォーマットのみ。**横長テーブル禁止（表は最大3列）**。

  ```
  **TICKER** $価格（日次%）
  　5日±%／一言の読みとアクション
  ```

- **⑤アクション（3分割固定）**:
  - **今やること**（なければ「なし」と明言）
  - **期限つきの待ち**（何を・いつまで・期限が来たらどうするか。「なんとなく待つ」を禁止する構造）
  - **次の判断日**

## 文体ルール

- 方向を語る主張には日付つき2点を添える。
- 株価は`latest_prices.json`由来のみ。Web検索の株価は使わない。
- 結論から。全体で読み切り2〜3分以内（差分版は1分以内）。

## 未反映・今後の作り込み候補

- 名前「盤面」は仮（ユーザー評: ダサい。ただし続投中）。
- 巡回トリガーの文面書き換えは、8/12のNBIS条件入れ替えと**同時に1回で**実施する（承認ダイアログを1回に抑えるため）。それまでの巡回は旧形式。
