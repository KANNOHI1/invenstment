# 定型レポート「盤面」仕様（ドラフトv0.1 — 名前・構成とも使いながらユーザーと作り込む。確定版ではない）

**起動**: ユーザーが「盤面」（または「盤面レポート」「盤面見せて」等）と発話したら、このレポートを生成する。

## 生成手順（必須）

1. `date -u +%Y-%m-%dT%H:%M:%SZ > watchlist/.price-refresh-trigger` → commit → push で株価を取り直す（GitHub Actions経由、約20-40秒）。`git pull`して`watchlist/latest_prices.json`を読む。**古いデータで書かない。`quoteTime`を冒頭に明記する。**
2. 並行して調査エージェントを1本立て、市況の定性情報（指数の方向・ドライバー・当日の主要ニュース）を取る。時間が惜しい場合はエージェントを省略し、既知の材料＋価格データのみで書いてよい（その場合は「価格のみ更新、材料は前回まで」と明記）。
3. 5層構成で書く。

## 5層構成

- **①マクロ**: 金利・雇用・インフレ・地政学・為替。今日の盤面全体を動かしている一番大きい力。
- **②資金の流れ**: ローテーション。何が買われ、何が売られているか。前回からの変化。
- **③テーマ**: 保有に関わる山（ネオクラウド/メモリ/AI物理インフラ等）ごとの状況と新材料。仮説登録簿（`thesis_register.md`）の反証条件チェック結果もここ。
- **④保有**: 銘柄ごとに縦型2行フォーマット。**横長テーブル禁止（モバイルで読めない。表を使う場合は最大3列）**。

  ```
  **TICKER** $価格（日次%）
  　5日±%／一言の読みとアクション
  ```

- **⑤アクション**: 今やること／やらないこと／次の判断日。ユーザーが実行すべきことがなければ「今夜やることはない」と明言する。

## 文体ルール

- 方向を語る主張には日付つき2点を添える（AGENTS.md準拠）。
- 株価は`latest_prices.json`由来のみ。Web検索の株価は使わない。
- 結論から書く。各層は短く。全体で読み切り2〜3分以内。
- 変化がない層は1行で流す（「①②は前回から変化なし」で可）。
