## 初期の見方

### 0. 国内証券会社フィルター

最終的な購入候補は、SBI証券、マネックス証券、楽天証券の少なくともいずれかで買付可能であることを必須条件にする。

今日時点の簡易確認では、`MU`、`SNDK`、`SIMO`は少なくともマネックス証券での導線を確認。`SIMO`はユーザー提供のSBI証券ログイン配下URLでも確認扱い。`MU`と`SNDK`は楽天証券の取扱リストでも確認済み。`SIMO`は楽天証券の公開取扱リストでは未掲載扱い。

詳細は`watchlist\broker_availability_2026-05-07.md`に分離して管理する。

### 1. 本命確認: SNDK / MU / WDC

この3つは、今の「メモリ / ストレージ再評価」山の中心。

- `SNDK`: 一番派手。EPSとデータセンター売上の変化が大きい。問題は、2,200億ドル超の時価総額からさらに3倍/5倍が許されるほど構造変化があるか。
- `MU`: すでに超大型だが、現在の利益水準が一過性でなければ大型株でも大きく動くという教訓を残す。
- `WDC`: SNDKほど話題化していないなら、比較対象として重要。FCFと粗利率が強い。

### 2. 小さめのレバレッジ: SIMO / P / NTAP

- `SIMO`: ADSベースの推定時価総額は約83億ドル。SNDK/MUより数学がかなり軽い。SSDコントローラ、特にMonTitanの利益レバレッジが本物なら見る価値がある。
- `P`: データ基盤としては良いが、FY売上+16%とFCF利回り約2.6%では、現時点の爆益性は`MU/SNDK/SIMO`に劣る。
- `NTAP`: 収益性は高いが、売上成長+4%で爆発力は弱い。次の2026-05-28決算で再加速がなければ除外寄り。

### 3. 良い事業だが倍率が重い: STX / DELL

- `STX`: AIデータ増加のHDD需要は本物に見える。ただし現在PERが高く、すでにかなり織り込まれている可能性がある。
- `DELL`: AIサーバー受注は非常に大きい。だがメモリ/ストレージ専業ではなく、AIサーバー/統合インフラ山で評価する方が自然。深掘り済み。

### 4. 決算待ち: キオクシア

キオクシアはSNDKとNAND供給網で近く、SNDKの数字が単独要因なのか、NAND全体の構造変化なのかを確認する鍵。

2026-05-15 15:30 JST予定のFY2025決算後に必ず更新する。
