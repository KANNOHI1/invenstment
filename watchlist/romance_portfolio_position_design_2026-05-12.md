# 200万円ロマン枠 横断ポジション設計 v0 - 2026-05-12

## 目的

これまで山ごとに作った購入候補を、実際に運用できる形へ落とす。

これは売買指示ではない。実際に買う前には、必ずその日の株価、時価総額、直近決算、次回決算日、SBI/マネックス/楽天の注文画面を再確認する。

この設計の前提:

- 防御的資産は別にある。
- ここは高リスク・高リターンのロマン枠。
- 目的は一般的な分散投資ではなく、非対称なマルチバガー候補を狙うこと。
- ただし、決算直前の未確認銘柄へ無理に全額を入れない。

## 基本方針

200万円を一括投入しない。

| 枠 | 金額 | 役割 |
| --- | ---: | --- |
| 初回投入枠 | 60万円 | 決算確認済みで、すでに候補化した銘柄だけを小さく入れる |
| 決算通過後投入枠 | 80万円 | `OKLO`/`NBIS`/`USAR`/`ONDS`/`MRVL`/`AMBA`/`DELL`/`AVGO`など、直近決算後に使う |
| 押し目・上方修正枠 | 60万円 | 仮説が崩れていない急落、または決算で仮説が強化された時に使う |

狙いは「全部を薄く買う」ではなく、決算を通過した強い候補へ資金を寄せること。

## 最終ポートフォリオの形

最終的な保有数は最大10銘柄まで。

理想形:

- 主力 3〜4銘柄: 各15〜25万円
- 準主力 3〜4銘柄: 各8〜15万円
- オプション 2〜3銘柄: 各3〜8万円

これ以上に分散すると、当たってもロマン枠全体への影響が小さくなる。

## 決算通過後投入の使い方

80万円は、今後数週間の決算で仮説が強化された銘柄へ入れる。

優先順位:

1. `OKLO` / `NBIS` / `USAR` / `ONDS` の直近決算組
2. キオクシアのNAND確認
3. `MRVL` / `AMBA` / `DELL` / `AVGO` のAIチップ山決算

決算通過後に見ること:

- 売上成長がテーマに沿っているか
- 粗利率が改善または維持されているか
- cash burn / FCF / debt / 希薄化が許容範囲か
- backlog / RPO / ARR / guidance が強いか
- 会社の説明が具体的か、PRだけか

## 決算前ルール

原則:

- 決算予定が7日以内の銘柄は、初回投入しない。
- どうしても入る場合は、ロマン枠全体の2〜3%まで。
- 決算跨ぎで入るなら、失敗時に即半値もあり得る前提でサイズを決める。

例外:

- 既に深掘り済みで、決算までに大きな材料が出た場合。
- 決算前に20〜30%下げ、かつ仮説が崩れていない場合。

## 損切りではなく仮説切り

このロマン枠は値動きだけで機械的に売らない。ただし、仮説が壊れたら売る。

共通の仮説崩れ条件:

- ガイダンスが大きく下がる
- 粗利率が構造的に悪化する
- backlog / RPO / ARRが売上に変わらない
- 大規模希薄化で株主価値が食われる
- 顧客集中が悪化し、追加顧客が見えない
- 公式資料で期待材料がMOU/PR止まりだと判明する
- 国内証券で買えない、または売買制約が強い

## 銘柄数を絞るルール

各山から全部買わない。

横断で見る優先順位:

1. 時価総額の数学が軽い
2. 直近決算で数字が出ている
3. 受注・backlog・ARR・RPOなど将来売上の証拠がある
4. 粗利率またはFCFが悪化していない
5. 国内証券で買える
6. 次回決算までの待ち時間が短すぎない

この基準で、最終的に10銘柄以内へ絞る。
