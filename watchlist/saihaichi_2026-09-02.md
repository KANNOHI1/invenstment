# 最終検証の結果（2026-09-02 夜）— **買付案は撤回**

## LEU: 「backlogが時価総額を上回る割安株」という読みが崩れた

| 検証項目 | 判明した事実 |
|---|---|
| backlogの質 | **LEUセグメント$37億のうち約$30億が「contingent（条件付き）」**。うち$24億はPiketon拠点の増設完成がマイルストーン条件。**10-Q本文と決算サマリー記事の説明が矛盾しており、一次資料でしか解けない** |
| 利益の質 | Non-GAAP $3,870万 vs GAAP $1,680万の差は、**株式報酬$1,770万＋拡張費用$1,060万を除外**したもの。どちらも継続的に発生する。**GAAPの方が実態に近い** |
| 希薄化 | 株数 2024年16.4M→2025年19.9M（**+21.7%**）→2026年Q1 22.4M。**ATM枠$10億が温存**（時価総額$3.4Bに対し巨大） |
| 競合 | **世界シェア5%未満**。米国内でもUrenco USA（480万SWU/年）が既に稼働、Oranoも参入準備。**「米国内唯一の担い手」は不正確** |
| ロシア論点 | CentrusはTENEX（Rosatom子会社）からの仕入れ転売契約も持つ。**禁輸は両刃**で、単純な追い風ではない |

**私が「backlog $45億が時価総額$3.4Bを上回る」と書いたのは、条件付き契約を確定契約として読んだ誤りだった。**

## この検証で見えた構造的な問題

**候補として調べた全社が「外部資金に依存しない」を満たさなかった。**

| 銘柄 | 資金調達 |
|---|---|
| IREN | 転換社債$6.3B、株数年+52.7% |
| SIMO | 転換社債$1.15B |
| CAMT | 転換社債$425M（転換価格超え・ヘッジ未確認） |
| LEU | ATM枠$10億、株数+21.7%/年 |
| KTOS | 2年で2回の大型増資、株数+44% |
| AVAV | 転換社債$650M＋増資、営業CF赤字 |
| UEC | 完全ATM依存、四半期売上$0 |

**自己資金で回っているのは MU・POWL・MOD の3社だけ。** そしてMUは3倍に$3,163Bが必要で、POWL・MODは象限不整合。

**つまり「小型で3倍が狙える」ことと「外部資金に依存しない」は、この市場では両立しにくい。**
成長中の小型企業は、定義上、外部から資金を取って成長する。**利上げフェーズはその形を罰する。**

**これが、この2週間の探索で本当に見つかったこと。** 銘柄の問題ではなく、条件の組み合わせ自体に無理がある。
